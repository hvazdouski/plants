# Telegram Bot - Справочник растений

Бот для получения информации о комнатных растениях.

## Развертывание на Render

1. Создайте новый Web Service на Render
2. Подключите репозиторий GitHub
3. Добавьте переменную окружения:
   - `TELEGRAM_BOT_TOKEN` - ваш токен от @BotFather

## Команды бота

- `/start` - начать работу
- `/plants` - список растений
- `/help` - справка

## База данных

В боте содержится информация о 5 растениях:
1. Алоэ Вера
2. Монстера
3. Фикус Бенджамина
4. Сансевиерия
5. Спатифиллум
